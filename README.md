# 升降杆独立调试工具

面向 DS2-P/R 驱动器的独立调试台，提供实机基础 JOG、模式17回零、模拟定位、寄存器观测和手动 Modbus RTU。仓库：<https://github.com/liuchang-t/lift-control-lab>。

本仓库位于 `~/project/lift-control-lab`，不导入原应用、不读写原平台配置。`baseline/` 保存 OMNI-Patrol `25cfe85` 的冻结证据，仅用于模拟对照；本工具不是已验收的原平台替换包。

## 启动

Python 3.8 或更高版本，仅标准库。在 WSL 中执行：

```sh
cd ~/project/lift-control-lab
python3 -m lab.server --config config.example.json
```

打开 <http://127.0.0.1:8765>。默认选择**真实设备并保持断开**；启动、查看页面、保存连接配置均不访问真实驱动器。核对网络串口服务器地址后，在页面确认真实连接并点击“连接”。改 IP、端口、从站或模式无需重启，下一次显式连接时生效。`--allow-real` 仅兼容旧命令，不会自动连接。

要离线试用，在页面选择模拟并连接。已明确保存的模拟配置在重启后继续生效；模拟启动可自动运行模拟器。默认真实模式不会覆盖用户保存的模拟选择。

通信为 TCP 字节流透传完整 Modbus RTU 帧（含 CRC），不是 Modbus TCP。串口服务器应使用 TCP 服务端、485 透传，其波特率、校验和停止位由服务器侧配置并与驱动器一致。示例地址不是自动探测或现场有效性保证。服务只监听本机回环地址。

## 当前可用功能

| 功能 | 实机 | 模拟 |
|---|---|---|
| 按住上升/下降、独立使能/失能、停止/软件急停 | 可用；JOG、强制DI给定、总线停止为不同通道 | 可用 |
| 模式17一键回零 | 现场成功顺序实现，当前版本获操作者功能测试通过反馈 | 可验证软件流程 |
| PP到位/全收/全升 | 暂禁用：使能兼容性尚待独立核实 | 可验证软件流程 |
| 独立PP/JOG速度、参数保存、报警建议、人工故障复位 | 可用 | 可用 |
| 寄存器监视、指令记录、手动485与自动CRC | 可用 | 可用 |

基础 JOG 使用 P0D-11 和 `0x4604`，不要求先回零、位置可信或处于软件工作范围。每次新点动读取 P0D-11，非1才发送使能1，然后发送上升17或下降33；不根据历史应答跳过检查，不先失能。松手发送停止并等待正确应答，连续点动保持使能，正反向均不等待静止。应答成功只代表命令设置成功，不代表电机已运动、停稳或功率级使能完成。

1. 连接后点击“检查 / 恢复”，核对设备条件。它不是权限申请，也不建立位置参考。
2. 保存 JOG 速度（cm/s），按住方向按钮，松手停止。失焦、页面隐藏和动作保活超时也请求停止。
3. 以实际 DI 限位信号禁止对应方向。950/952 不用于猜测方向；两个限位均未触发时不因残留警告阻止点动，也不要求重新检查。
4. 若“命令已应答，未检测到运动”同时存在950，界面提示驱动器内部**可能**仍在阻止运动：先松开，停止应答后点击“人工故障复位”，再手动点动。不会自动复位；952未验证，不套用此结论。
5. 报警（包括过载或未知码）仅显示含义和建议，不按报警码阻止操作；由操作者判断并按需人工复位。软件急停后也需要重新检查。普通松手、无运动提示不会单独导致锁定。

顶部“停止”固定发送P0D-08=256，“软件急停”发送512；有本工具JOG上下文时额外撤销点动请求，并通过实际反馈确认静止。松手仍使用JOG专用快速停止，二者不混用。报警（包括未知码）不单独封锁使能、失能或人工尝试复位；处置建议与手册复位能力仍展示。

私有客户端共享同一后端，不需要获取/续租控制权。外部控制端引起的运动仅观测，不以“本工具没有运动任务”为由自动干预。断开或退出时，仅对本后端仍有的活动任务执行停止流程；纯监视直接断开。

## 配置、速度与坐标

加载优先级由低到高为：程序默认值 → 可选 `--config` 启动文件 → `.runtime/config.json` 页面参数 → `.runtime/connection.json` 连接设置。示例只提供初值，不能覆盖页面保存值；保存文件损坏或非法会明确报错，不静默恢复默认值。

当前交付配置：

| 参数 | 数值 |
|---|---|
| 软件下限 / 全收位置 | 1cm |
| 软件上限 / 全升位置 | 182cm |
| 实测行程参数 | 183.7cm |
| 控制台机械比例 `cm_per_rev` | 0.35921486cm/电机转 |
| 当前每转指令单位 | 10000，核验依据及限制见协议文档 |

高度显示为升降杆**伸出高度**，不叠加安装高度或收回长度。实测比例统一用于高度和速度，不修改驱动器电子齿轮。设每转指令数为 N、机械比例为 L，则位置计数差换算为 `Δ计数×L/N`，速度换算为 `rpm=cm/s×60/L`、`cmd/s=cm/s×N/L`；整数写入统一使用半值远离零舍入。

PP 与 JOG 分别保存 cm/s 速度和独立上下限，比例仅辅助显示；旧 API/配置键 `pv` 现在对应基础 JOG，不代表实机使用 P10 PV 启动。速度按设备身份保存在 `.runtime/profiles/`，重启恢复期望配置，不恢复运动、使能或可信参考。参数保存采用原子替换，保存前独立确认实际静止；这一检查不增加普通JOG松手或反向点动的等待。改变机械比例不按比例缩放用户保存的 cm/s，越界会明确拒绝。

PP 在参考可信时可以从软件范围外返回范围内任意目标，仍受方向限位、可信参考和单次位移限制。全升/全收是端点定位，不是寻找限位开关。当前单次默认计数上限对应约102.7cm，较远目标需要分次或明确调整参数。PP目前仅在模拟开放。模式17回零采用参数准备 → P03-07=1给定 → P0D-08=128；保持P0D-17=0，按本次DI、完成位、位置及转速确认参考，不要求950/952，不自动定位到1cm。

回零调试参数可分别保存P10-36搜索速度、P10-38爬行／查询速度（指令单位/s）和P10-40回零加减速度（指令单位/s²）。留空沿用驱动器当前值；保存不下发，下次回零准备阶段逐项写入并读回，再使能启动。保持参数使用秒，不能与加减速度混淆。

## 监视与手动报文

状态栏保持可见，操作、寄存器和报文记录各自滚动。寄存器显示固有 R/W 属性、读取机制、真实03读回及整秒时间，按地址排序；所有主值均来自读回，最近写应答在值的悬停信息中辅助显示。P03-06/07、P0D-17/18 和 DI3 供配置给定/输入观察，不能据此确认功率级使能完成。

位置、转速、DI、报警、P0C-13 等保持保护采样；动态参数分组轮询；电子齿轮、每转指令数、DI功能等固定配置按需读取，工作中不反复扫描。显式刷新逐块真实读取，运动或手动接管期间也可读取；部分失败明确列出，旧值不伪装为新读回。低频新鲜度按其扫描周期判断；具体目录和边界见[寄存器说明](docs/registers.md)。负载目前显示原码及有符号解释，倍率尚未核实，不显示虚假的百分比。

手动窗口支持03/06/10和自动CRC，发送前展示完整帧。读取不取消正常任务；确认后的写入直接接管并取消普通任务，不自动插入停止、使能或复位。报警、限位、位置参考、检查状态及普通运动锁定不拦截手动写；软件急停状态下的新手动写也可发送，但不解除普通运动急停。手动期间继续显示反馈和通信诊断，不因报警、反馈失鲜或失败自动插入控制帧，也不自动重发原始写入。用户主动停止仍可用，取消尚未发送的旧请求；后续明确的新手动请求不因此永久锁定。格式、CRC、连接目标和响应匹配校验仍执行。原始写撤销普通流程参考，结束手动后重新检查。

日志缓冲最多20,000条，支持清空、暂停、翻页和导出。向上查看时冻结视图，后续轮询不会滚动覆盖正在看的内容。重启清空内存日志；需要保留测试证据时及时导出到被忽略的 `.runtime/`。

## 实机边界

P0D-17=1 屏蔽物理限位反馈已被现场观察，基础JOG与HOME运动期间保持0，HOME静止收尾采用下述强制DI切换和实验性保持。HOME采用现场成功的P03-07极性给定路径（核验DI3功能1且原始高电平），当前版本已获操作者功能测试通过反馈；PP旧路径继续禁用。P0C-13连接后读取，非0阻止预检，不自动修改。驱动器软限位行为、RS485断链自动停机及功率级使能完成判据仍无充分依据，不自行假定。

本设备无电机抱闸，传动系统自锁。自锁不能代替动态停机验证。通信完全中断时，上位机无法保证停止指令送达；模拟通过不能证明实机停止距离、满载行为或断网保护。详见[验证边界](docs/validation.md)。

## HOME失能收尾与故障恢复

HOME收尾在给定读回和DI3状态核对后，分别执行可配置的实验性最短保持：home_enable_hold_s默认4秒、home_disable_hold_s默认0.2秒。可在页面“调试参数”保存，重启后继续生效。保持期间持续核对给定、DI3、转速和位置；异常进入停止处理。该配置已有操作者确认实际失能的成功样本；输入状态、保持结束和最终读回仍不是功率级完成判据。

独立使能/失能按钮仍使用各自P0D-17/18组合并逐条读回；不自动启动运动。Er.601出现后自动停止仅确认静止，保留驱动报警供人工处理。点击人工故障复位才执行失能收尾；报警已清零时不再写复位，仍为601才单次写P0D-01并确认清零。恢复检查通过后才允许用户重新点击回零；不自动回零、不恢复可信位置、不解除急停。

完整顺序和参数说明见[指令流](docs/control-flow.md)。完全断链时不能保证总线停止指令送达；实际停机仍需独立手段。
