# 调试工具架构与控制决定

## 模块边界

```text
网页 / HTTP / Bridge
  server.py → service.py（共享客户端、连接生命周期、Bridge边界）
                    ├─ mqtt.py（只读发布）
                    ├─ readiness.py（当前条件和恢复步骤）
                    ├─ manual_bus.py（原始RTU校验，手动写优先接管）
                    ├─ registers.py（观测缓存与寄存器目录）
                    └─ controller.py（运动、HOME、停止、恢复、参考可信度）
                         ├─ model.py（配置、原子保存、按设备隔离的用户速度）
                         ├─ units.py（单位、舍入和目标范围唯一来源）
                         ├─ alarms.py（手册字典与平台策略）
                         └─ driver.py（只读预检、参数快照、PP/PV/HOME、人工复位）
                              └─ baseline/lift_modbus.py（冻结的基础报文编解码）
                                   └─ transport.py（RTU透传 / 寄存器模拟器）
```

冻结基线从原代码 AST 提取适配类，使用私有命名空间和模拟寄存器，不导入原应用。候选实现不调用已知有缓存问题的旧高层运动方法；不修改冻结证据。

## 速度和单位

PP/PV 各自有上下限与用户期望速度。上下限配置为 Pr/s；期望速度以 cm/s 持久化，修改最大速度不会把已保存的物理速度按比例缩放。当前模式修改速度时下发并读回，另一模式仅保存；0 停止对应模式。实际反馈 rpm、确认写入的速度和期望速度分别表达。

`units.py` 是候选的唯一换算来源。P0B-07 和运动目标按手册的“指令单位”处理；P0B-15 等编码器原生单位不能混入。写整数寄存器采用半值远离零舍入，内部厘米不提前保留两位，显示精度独立。前端不硬编码每转计数与导程。当前N=10000指令单位/电机转、L=0.35cm/电机转沿用原配置：cmd/s=v/L×N，rpm=v/L×60。L不是驱动器手册可证明的机械事实。P05-02为0时，N=编码器线数×分母/分子只能作为与默认值和案例自洽的候选关系；手册未明确零值回退优先级，实际N和L仍须现场核验。

速度配置按连接身份和模拟/实机隔离，版本化、原子保存。首次迁移按旧 30% 比例生成独立初值；损坏或越界不静默降级。启动文件显式指定优先，否则加载本工具保存配置。零点可信度、使能和运动意图不随文件恢复。

机械比例`cm_per_rev`为控制台配置。实测校准只修改该L，不通过改电子齿轮重定义驱动器坐标：新L=旧L×实测位移/指令位移。修改后撤销控制许可和可信参考，重新预检/回零；期望PP/PV cm/s设置保持不变，按新比例重新换算。保存前必须验证原物理速度仍能落在新换算后的允许范围，不能用比例缩放掩盖越界。

## 回零与三类边界

现场事实：无电机抱闸；升降杆传动系统自锁。模型不把自锁当作瞬时动态制动。

机械上下端点在最外层，限位开关在其内，日常软件工作范围在开关内侧。机械端点不被视为可无损撞击的控制手段。参数缺失时不能凭模拟器位置推定真实机械尺寸。

HOME 模式 17 以负限位释放沿建立参考。控制器进入专门回零状态，禁止并发普通运动；要求本次启动证据、回零完成状态变化、静止反馈、正确参考与可接受限位状态。停止、超时、丢包、重连或异常后参考保持不可信。不能用启动前已有的完成位或任意最终静止位置重新定义零点。

全收使用 PP 到 `soft_lower_cm`，默认回零参考上方 1cm，界面仍显示 1cm。全升使用 `soft_upper_cm`。普通人工“设收回零点”入口关闭，避免引入第二套任意坐标。HOME 预期的下限位事件仅在该流程处理，不全局忽略 952。

PP 启动前验证可信参考、新反馈、方向、目标范围及单次位移。PV 根据剩余距离及停止模型提前减速/停止。减速度、通信延迟和余量在真实设备上必须验证。上位机轮询不能保证网络彻底中断时停止。

正常控制中的 P0A-40/41/43 和 P10-18/20 只读；是否关联、是否覆盖 PV/JOG、HOME 例外、触限减速行为未从手册确定。界面明确“待实机验证”，不自动设置，也不宣称模拟已证明它们有效。

## 状态与并发

普通运动转换串行执行。stop/estop 先登记意图、递增命令代次，使未完成启动失效；每个有限时长启动步骤检查代次。停止状态持续到反馈确认，通信失败不能伪装静止。独立保活与运动保护监测不依赖前端轮询。

模式切换、HOME与人工复位使用同一设备执行边界。私有客户端共享操作，不设独占持有者、获取/释放、续期或租约超时停止；旧lease接口仅兼容无操作。客户端标识用于事件关联，不能作为控制权限门槛。停止优先、启动代次、PV动作心跳和参数保护仍保留。Bridge的显式启用与token边界不变，不自动开放公网。旧`release_enable_s`仅保留配置兼容，候选实现不再延时自动去使能，以免任务结束后干预外部主机运动。

## 报警与人工复位

`alarms.py` 对应手册 PDF 第27～30页全部故障/警告条目，保存原始值、代码、中文名、手册类别、可复位标注、检查建议和来源。平台策略单独定义；手册“警告”不代表允许继续运动，“可复位”不等于可直接重启。

所有非零报警阻止新运动，运动中请求停止；仅条件明确的 950/952 与有效实时 DI 允许反向脱离，HOME 有明确的负限位流程例外。未知码保留原始证据并保守阻挡。涉及编码器/坐标的报警使参考失效。

人工故障复位为本地维护操作：确认已处置原因、确认停止、按允许策略发送一次 P0D-01=1、重新读取报警。复位不自动使能、不重发旧目标、不恢复位置可信度。不可复位、未知及特殊维护类报警拒绝通用复位。正常控制不会自动初始化、清多圈、调整保护阈值或写 P0C-13；手动总线明确确认的原始写报文另按接管规则处理。

## 参数权威性

用户期望配置、驱动器实际值和本次有效值分开。位置、DI、报警进入实时内存；设备参数快照只作诊断。实际读回的更宽松限位不能覆盖已确认的工作范围。HOME 参数、电子齿轮、方向、字序与 DI 配置发生差异时需核验，不通过自动接受差异来维持运动。

## 动态参数监视

快速状态和参数检查分层。位置/转速、DI、报警、EEPROM状态维持保护采样；其余关键参数按分组分频读取，不能把完整寄存器目录塞进每个快速状态周期而延迟停止请求。启动前的完整核验与运动期间的分组检查互补，必须公开完整扫描时限和最后读取时间。当前MONITOR_GROUPS为11块，单块间隔至少0.5秒，名义全轮5.5秒；控制序列和总线忙时让行，本后端活动任务期间最旧监视值超过12秒请求停止。活动PP/PV的模式、当前目标/速度及HOME活动参数每保护周期另外核对。

风险分类将单位/参考参数、运动及停止参数、普通诊断值区分。单位比例、电子齿轮、字序或参考相关配置变化必须防止旧坐标继续用于软件限位；模式、目标、速度与减速变化不能默认为控制器的新意图。本后端活动任务中检查失败才请求停止；空闲观测只更新诊断并按风险撤销许可/参考，不向外部运动发送停止。工具自身写入须由该次有边界的控制序列登记并读回核验后更新预期，未知变化不得以“刷新基线”自动吸收。读取失败和整轮扫描过期需要明确状态，不能继续展示为已核验。

用户界面将时间舍入为整秒仅用于展示，内部monotonic时间、控制延迟和保护阈值不因此变更。电子齿轮推导值、工具配置、原始读回字与现场验证结论分别保存/显示，不把P05-02低字、候选推导或机械L配置自动提升为硬件事实。

轮询无法保证完整捕捉两个读取间发生又恢复的改动。外部主机/485控制端的运动不归本后端任务管理，位置和转速变化仅显示，不以“没有本工具意图”为由自动停止或自动撤销位置参考。命令触发寄存器不能作为持久状态读取；未监视参数、另一主站的并发控制、硬件输入和固件生效时机仍是显式残余风险。

## 连接生命周期

当前连接与待连接目标分离，目标包含模式、主机、端口、从站和超时。编辑模式和保存连接配置不触发网络动作，只有显式连接才应用目标；页面real连接需额外明确确认，命令行直接real保留`--allow-real`门槛。

切换或断开遇到本后端活动任务或停止待确认时，先撤销旧运动意图，确认停止，再关闭采集/保护任务与传输；纯监视直接关闭，不发送停止帧干预外部控制。停止失败保留旧控制器、传输和保护任务，不创建新目标连接或伪装断开。成功建立新对象后仅开始观测，控制许可与位置可信度均重新建立，不沿用旧对象的使能/目标/位置。仅同一已验收真实身份重连可保留停止模型验收标记；模拟转实机或更换真实目标使其失效，不以连接确认代替现场验收。

断开是明确状态，不依赖TCP传输的懒连接行为表达；设备操作、主动刷新和参数读取必须在服务层检查连接状态。GET状态与寄存器可返回标明来源和新鲜度的缓存，但不能因读取页面而创建真实连接。连接状态转换与普通操作串行，停止意图仍优先于正在准备的动作。

## 手动总线与寄存器观测

手动接口和正常控制共用同一传输对象及串行事务边界，不额外创建真实设备连接。03读取不撤销自动运动。首次确认06/10写入立即取消旧自动意图并确认停止，然后取得普通序列锁发送原始报文；无需预先进入独立维护模式。普通启动不能穿插到手动接管中。手动接管状态独立监测反馈新鲜度、报警、连接周期与停止意图；出现不确定结果即锁定写入并请求停止，不重试原始写入。已有报警时，单寄存器P0D-01=1人工报文允许暂缓报警锁定至复位读回完成，其他保护仍生效。

任意原始写报文不能纳入正常PP/PV软件范围保证。手动写撤销位置可信度；退出需确认停止，恢复普通操作需要重新预检和回零。手动内容可包含P0C-13或软限位参数，必须与正常流程“不自动改写”的约束区分。停止及急停始终可请求，不能因写入接管而被屏蔽。

`RegisterMonitor`被动采集已验证请求/应答，不新增高频轮询。两字参数仅在同一事务和连接中完整观测时组合，避免把不同时间读到的半字拼成伪造值。写应答标记`write_ack`，读响应标记`read`；连接变化、超过有效期、未完整观测均有明确状态。主动完整刷新仅在空闲执行，不读纯命令触发寄存器来假装当前控制状态。

## 操作条件与恢复提示

`readiness.py` 依据当前控制器与设备观测产生操作条件与恢复提示；前端显示这些条件和最近拒绝原因。提示是诊断视图，不替代命令执行时的再次校验。回零、人工复位、软件急停和普通停止的恢复流程分别表达，不统一归类为“重新启动”。

回零后参考位置可能低于默认1cm软件下限，提示要求先使用全收返回工作端点。速度为0、单次位移超限、PV剩余距离不足、设备参数不一致和EEPROM设置问题必须提供各自的处理建议，不能一律建议重新检查 / 恢复。未知参考时不承诺950/952可由普通点动脱离。

界面固定状态/停止区域，工作面板内部滚动。设备观测、普通操作、寄存器与手动报文并列；开发用集中平台对照和故障注入不在用户操作面板出现。解释性信息进入悬停提示，当前拒绝原因和恢复步骤保留在可见提示区。

## 实机验收边界

离线测试覆盖软件分支、报文和故障注入，不证明惯性、自锁承载、开关响应及串口服务器行为。移植原平台前须完成 HOME 可重复性、满载停止距离、DI 强制与物理限位关系、驱动器软限位适用性、断网/掉电及复位后的参考策略验收。本仓库不是已经验收的生产替换包。
