# 位置比例校准

当前换算为 `高度=(P0B-07-参考计数)×L/N`；N为每电机转指令数，L为控制台保存的cm/转。校准只修改控制台比例，不写驱动器电子齿轮，不把开关位置重新定义为回零位置。

## 已提供的两点测量

底座直接落地，同一顶部法兰测量：下限位86.3cm、P0B-07=-1224；上限位270cm、P0B-07=5112707。以计数差计算，避免界面两位小数舍入误差：

- 实测开关间行程：183.7cm。
- 计数差：5113931指令单位。
- 校准前N=10000、L=0.35时计算行程：178.987585cm；少算4.712415cm，较实测低2.5653%。
- 实测比例：0.00003592148583936702cm/指令单位，约27838.4921指令单位/cm。
- 比例修正系数：1.02632816684。保持N=10000，则计算L=0.359214858394cm/转；当前保存值为0.35921486。

两点测量直接确定的是L/N，不能独立证明实际电子齿轮、每转指令数或电机导程。当前只读缓存P05-02=0、编码器131072、齿轮分子131072/分母10000，候选推导N=10000与配置一致；这仍不是固件真实比例的独立验证。候选L作为控制台有效校准系数解释，不擅自修改驱动器参数。

参考计数保持0时，校准后下限位约-0.04397cm、上限位约183.65603cm。下限位略低于回零参考并不要求重设软件零点。落地测量的法兰高度约为86.34397cm加该伸出坐标，仅作计算说明，调试台仍只显示伸出高度。

当前现场参数为L=0.35921486cm/转、软件下限1cm、上限182cm、行程183.7cm；高度、PP速度与JOG速度共用换算模块。校准不修改驱动器电子齿轮，不改变已保存的cm/s期望速度。示例配置提供这些现场初始值，页面保存后的配置优先于启动示例，重启仍生效。应用L后，位置与cm/s、rpm换算一起变化；保留相同cm/s时，对应rpm约乘0.9743472。软件范围仍由独立参数定义，上限182cm较校准上开关位置低约1.656cm，不自动扩到开关端点。两端数据只能给出全段平均比例，不能证明全程线性或往返一致性。

## 保存与加载

页面保存控制台参数写入`.runtime/config.json`，连接设置独立保存为`.runtime/connection.json`，PP/JOG期望cm/s按设备身份分别保存在`.runtime/profiles/`。加载顺序为模型默认值、可选启动配置、页面保存配置、保存的连接设置，后者覆盖前者；损坏或不合法的保存文件明确报错，不静默退回示例。运行数据不纳入Git。

默认真实模式启动后保持断开，重启不会重新连接、恢复使能/运动或位置可信状态；操作者仍可显式选择模拟模式。保存机械参数只改变控制台换算，不写P05-02或电子齿轮。软件上下限是独立参数，修改L不会自动把它们扩展到开关位置。

## 每转指令数的依据及机械解释

厂家《DS2-PR 485串口案例》PDF第3页明确以默认细分10000示例：50000指令单位为正转5圈、-20000为反转2圈、10000指令单位/秒为60rpm。第9页还示例P05-02=1000后1000脉冲转一圈。因此10000有官方示例依据，但属于配置量，不是所有设备永远固定的物理分辨率。

用户手册PDF第14页定义P05-02为每转位置指令数（默认0），电子齿轮默认131072/10000。当前缓存也为P05-02=0、编码器131072、齿轮131072/10000；候选关系与官方示例自洽，但手册未完整说明0值回退规则，不能仅凭寄存器读数认定固件有效配置。

L是每电机转带来的顶部伸出量，不一定是丝杆导程。单级丝杆可写为`L=丝杆导程/减速比`，减速比定义为电机转数/丝杆转数；有联动伸缩级时还要乘机构位移倍率。多头丝杆导程=螺距×头数。

实测L约3.59215mm/电机转。假设单头6mm导程且无其他位移倍率，则减速比约1.67031；若真实齿数比为5:3，等效L恰为3.6mm/电机转。按该比例推算同一计数差的行程为184.101516cm，比183.7cm实测多0.401516cm（约0.219%）。这是合理候选结构，不是已确认事实；测量误差、机构间隙及伸缩联动也可能参与差异。需要机械图、齿数/导程或电机转数与位移的独立测量来区分，采用用户确认的实测值0.35921486cm/转，不改成0.36，也不把长小数当作制造标称导程。
