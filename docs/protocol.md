## 确定的协议

RTU over TCP 透明串口透传，不加 MBAP。0x03 读、0x06 单写、0x10 多写；CRC16 Modbus 低字节先发。每个 word 内高字节先发；案例默认双 word 为低 word 在前。P0C-26 可改变字序，应核验。

| 参数 | 地址 | 用途 |
|---|---|---|
| P02-00 | 0x0200 | 9=Modbus，总线模式，断使能设定 |
| P10-03 | 0x1003 | 1=PP，3=PV，断使能设定 |
| P10-14 | 0x100E | 32 位 PP 目标 |
| P10-25 / 42 | 0x1019 / 102A | 32 位 PP/PV 指令单位每秒 |
| P0D-08 | 0x0D08 | 1相对，3绝对，16/32点动，256停止，512急停 |
| P0D-17 / 18 | 0x0D11 / 0D12 | DI 强制开关/位图，不是抽象使能 API |
| P0B-00/02/03/04 | 0x0B00/02/03/04 | 转速/负载/DI/状态 |
| P0B-07 / 34 | 0x0B07 / 0B22 | 32 位位置 / 报警 |
| P03-08..11 | 0x0308..030B | DI4/5 功能及极性 |
| P0C-13 / 26 | 0x0C0D / 0C1A | EEPROM 更新 / 双字字序 |

## 单位与换算证据

手册明确区分指令单位、转速与编码器单位：P10-25（PP速度）和P10-42（PV速度）单位是指令单位/s；P0B-00是rpm；P0B-07绝对位置计数是指令单位，P0B-15才是编码器单位。不能用编码器分辨率直接解释P0B-07，也不能把P10速度数值直接当rpm。

候选工具沿用原项目 `pulses_per_rev=10000` 和 `cm_per_rev=0.35`。此处cmd表示位置指令单位，N表示每电机转对应的cmd数，L表示每电机转对应升降距离：

| 换算 | 公式 |
|---|---|
| cm/s → rpm | `rpm = v_cm_s / L × 60` |
| cm/s → cmd/s | `v_cmd_s = v_cm_s / L × N` |
| rpm → cm/s | `v_cm_s = rpm / 60 × L` |
| 位置cmd → cm | `height_cm = (position_cmd - reference_cmd) / N × L` |

使用默认N=10000、L=0.35时，0.35cm/s对应60rpm和10000cmd/s，1.05cm/s对应180rpm和30000cmd/s。UI显示精度不参与整数指令计算；候选写入整数采用统一的半值远离零舍入。

用户手册PDF第12页明确列出P00-31“编码器线数L”、P00-32“编码器线数H”，范围131072～8388608；二者是低/高部分，不应把单个低字当作完整编码器分辨率。PDF第14页列出P05-02“电机每旋转1圈的位置指令数”，范围0～1048576 P/r、默认0；P05-07电子齿数比分子默认131072，P05-09分母默认10000，分子分母范围均为1～1073741824。

在通常“编码器计数/指令计数”的齿轮定义下，可作候选推导 `N = encoder_counts_per_rev × denominator / numerator`。默认值给出131072×10000/131072=10000，与串口案例PDF第3页的50000指令单位=5圈、10000指令单位/s=60rpm一致。**两份手册没有明确写出该公式，也未完整说明P05-02=0时的优先级/回退规则**，所以这是依据参数名称、维度和案例交叉校验的推导，不能标为厂家已确认或实机已验证。读回自洽只能证明候选关系一致，不能证明该固件当前有效比例。

P05-02还有寄存器宽度歧义：参数表上限1048576超过16位，但串口案例PDF第9页用功能码06向0x0502单字写1000。单字写较小数值可能只影响低字，也可能反映手册/固件差异，不能单凭这条案例断言该参数只有16位。调试观察应保留0x0502与相邻高字的原始证据；高字非零不得静默丢弃。实际宽度、P0C-26对双字解码的影响，以及参数需要重新上电才生效等行为必须按当前固件核实。

L=0.35cm/rev来自原项目配置，手册不包含升降杆机械传动结构，不能据该手册证明其正确。现场需验证电机圈数、实际位移、方向和电子齿轮共同决定的比例。模拟器使用同一配置，因此模拟读数自洽也不能独立证明真实机械换算。

现场修正仅针对上位机机械比例`cm_per_rev`：`新L=旧L×实测位移/指令位移`。测量应采用同方向、足够行程、避开限位和机械间隙影响，并通过多次重复确认。驱动器电子齿轮、编码器线数及P05-02只作为读回依据与变化检测项，不要求为校准厘米显示而调整它们。PP/PV的cm/s用户设置保持原值，仅重新计算发送指令；超出新换算后的速度范围须明确拒绝。

## 已核对的笔误

1. 案例第10页：50000 的 `C3 50 00 00` 正确，但说明把 100E/100F 的高低 word 写反。
2. 同页 `01 06 02 00 00 09 88 72` CRC 错；应为 `48 74`。
3. 案例第7页：PT 启动 `00 64` 是十进制100，而参数表64应编码 `00 40`，完整 `01 06 0D 08 00 40 0B 54`。
4. 同页 `01 06 10 03 00 04 3D 0B` CRC 错；应 `7C C9`。
5. 用户手册第32/33页 CRC_H/CRC_L 标签与正确 RTU 线序相反；示例低 word 先发与数值转换相符。
6. 用户手册第33页多写请求 word 数2，响应表却列4；实现应校验响应等于请求数，不能跟随错误示例。
7. P0D-08=0 是无效/控制字复位，不应当作通用运动停止；256 是运动停止，不是仅 PV 可用。

P0C-26 表未完整标注两个选项数值，不能凭该表杜撰取值映射。工具实机字序核验需要操作者给出已核实的低字优先参数值。P0B-02 负载来自案例；新版参数表重点列 P0B-12 平均负载，不能未经厂家确认擅自互换。

## HOME 模式17与坐标参考

用户手册 PDF 第40页（页脚38）定义模式17：负限位未有效时先向负方向搜索，触发后反向；以负限位释放沿建立参考。开始时已在负限位上，则向正方向离开。P0B-04 Bit3 是回零完成（PDF第18页）；P0B-07 是指令单位的绝对位置计数（第19页）。

| 参数 | 地址 | 工具用途 |
|---|---|---|
| P10-03 | 0x1003 | HOME运行模式值6 |
| P10-16 | 0x1010 | 原点偏移，32位，只读核验 |
| P10-35 | 0x1023 | 模式17；启动前核验已有配置，不替换未知方式 |
| P10-36 / 38 | 0x1024 / 0x1026 | 回零搜索/爬行速度，32位，读取现有值 |
| P10-40 | 0x1028 | 回零加减速度，32位，读取现有值 |

串口案例第9页演示的是模式19，不可把其方向直接移植为现场模式17。HOME最终停止位置可能与原点事件位置有偏差；工具校验确认过的原点偏移与位置容差，不把每次最终反馈任意抵消成零。只有本次完成状态变化、静止和限位条件均满足后才建立可信参考。普通全收默认回零参考上方1cm，显示也是1cm。

## 报警证据与复位边界

`lab/alarms.py`覆盖第27～30页故障表和警告表全部59项。每项保留手册类别、能否复位、中文名、处置建议与PDF页码；平台是否允许通用复位另列策略。未知码保留原始16位值并阻止运动。只对原实现曾记录的6B00、6620、E950、E952作显式别名解析，保留其“待实机验证”来源，不普遍截掉任意高位。

故障复位P0D-01=1不等同于初始化、清编码器多圈或解除物理限位；工具不执行这些附加动作。手册标为“可复位”的编码器特殊维护报警，仍可能禁止通用按钮复位。950/952只有物理限位均已释放时才允许人工清除滞留报警；有效开关不能靠复位绕过。

设备前提由用户明确：电机无抱闸，升降杆传动自锁。625/626仍保留在完整字典中，建议核查抱闸保护配置和型号，不指导检查不存在的抱闸。自锁不能证明停止距离或掉电瞬间无位移。
## 原始手动报文边界

原始手动RTU支持03/06/10，并严格校验CRC、当前从站、字节长度和寄存器数量。手动写由用户明确确认，可以优先接管自动流程；因此本文中的“只读”指正常控制算法和自动检查，不代表手动报文接口的写白名单。原始写不自动遵循软件行程、速度和EEPROM策略，页面可按默认开启的自动CRC选项追加校验字节，但不修改报文的功能、地址或数据；关闭该选项时完整帧原样校验，后端始终要求合法完整RTU。详见[手动总线与寄存器目录](registers.md)。
