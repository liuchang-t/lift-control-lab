# 工作项 LIFT-LAB-001：独立升降控制调试工具

本工作项是独立调试工具的稳定协作入口，描述当前范围与验收约定，不作为逐轮会话记录。代码位于 `/home/liuchang/project/lift-control-lab`；原平台 `/home/liuchang/projects/patrol-platform` 不在修改范围。`analysis.md` 保留原平台冻结提交的分析证据，不能将工具改进解释成原平台已经修复。

## 目标与范围

提供可观察、可重复测试的升降杆调试工具，保留手动总线、寄存器监视、报警解释与处置建议。默认启动选择真实设备，但保持断开；只有明确点击连接并确认目标后才访问设备。模拟模式用于离线验证，模拟能力不等同于真实设备能力。

- 真实基础JOG使用官方软件抓包确认的P0D-11及0x4604，保持物理DI有效，不要求回零、可信位置或软件高度范围。
- HOME按现场成功的参数→P03-07=1→128顺序实现，运动期间保持P0D-17=0，当前版本已获操作者功能测试通过反馈，专项边界见验证文档。PP定位、全收/全升仅模拟开放，真实设备旧强制DI使能路径继续禁用。
- PP/JOG独立保存期望cm/s和速度范围，统一高度、cmd/s与rpm换算。现场L=0.35921486cm/转、N=10000、软件范围1～182cm、行程183.7cm。
- 页面保存配置优先于启动示例；连接目标、设备速度配置独立持久化；重启不恢复运动、使能或位置可信状态。
- 私有客户端共享操作，无独占控制权或租约体系。检查 / 恢复是运行条件检查，不是权限授予。
- 紧凑单页显示状态、操作条件、下一步、寄存器与指令日志。手动报文可自动计算CRC，明确确认的写入直接接管普通任务，不受普通运动条件门禁。

非目标：修改原平台；自动连接、试动或故障复位；自动改写P0C-13、电子齿轮、驱动器软限位；驱动器初始化、清多圈或自学习；发布、部署服务。Git提交属于用户单独授权的交付操作，推送另按明确授权执行。

## 控制和恢复验收

1. HOME清理仅在本工具尚持有该使能请求时进入点动准备；不得仅凭P03-07=1改写DI3极性。每次新JOG先读取P0D-11；当前为1才省略使能写，不以历史ACK跳过。读取失败不继续启动，不先失能再使能。
独立“使能”按钮在静止后依次执行P0D-17=1、P0D-18=507，并保持强制DI；独立“失能”按钮先停止并确认实际转速/位置静止，再依次执行P0D-17=1、P0D-18=511、P0D-17=0。每步复用强制DI写入/03实际读回核对，正确才执行下一步，不以后台轮询或写回显替代；失败中止当前序列并进入停止待确认。按钮不发送JOG使能命令，不启动运动；不改变基础JOG或HOME自身的使能方式。给定读回一致不证明功率级完成。

2. JOG各写入以正确匹配应答确认设置，普通停止同样只确认命令应答，正反向接续均不等待静止。合并重复停止，隔离旧会话迟到松手；ACK不得描述为机械已静止或功率级已使能。
3. JOG方向仅由有效的当前物理限位决定：单侧触发禁止继续向该方向、允许反向；两侧触发或信号未知禁止。950/952残留不单独停止、锁定或要求检查；报警只提示，物理限位、松手、保活和通信保护保留。
4. 无运动仅显示诊断，不自动锁定或要求检查。已应答、未检测运动且950存在时，提示驱动器内部可能仍阻止运动，建议松手后人工复位；952尚未验证，不类推，不自动复位。
5. 人工故障复位保留明确确认、停止及报警策略检查。950/952人工复位不要求限位先释放，物理限位方向保护仍独立生效；成功清除仅保留原本有效的检查状态，不创建许可、可信参考，不解除既有急停，不重启运动。
6. HOME需实际DI触发/释放、本次完成位、参考位置与静止条件成立才建立参考，不要求950/952，不设固定完成延时；取消、超时和重连不建立虚假参考。可信参考下即使当前超出软件范围，PP仍允许到达范围内目标；非法目标或未知参考仍拒绝。
7. 后端只保护自身活动任务，不因观测到外部运动自动停止，也不单独因此撤销参考。通信中断时请求停止不代表断链后的物理停机已保证。

## 观察与配置验收

- P0D-11真实03读回与写ACK独立保存；主值来自读回。P0D-17/18给定读回与DI3实际观测分别显示，不据此声明使能完成。
- 快速反馈、当前运动相关参数、低频动态参数、按需固定参数明确分类。每转指令数、电子齿轮和DI4/DI5功能不连续轮询；DI3功能P03-06与极性P03-07合并快速读取，用于HOME给定核对。其余静态配置外部改动无法即时发现，该边界应明确。
- 新鲜度与读取周期匹配：动态轮转名义2.5秒、有效期12秒，快速项按对应周期，按需项不因经过数秒显示过期；断开或换连接仍使旧观测无效。界面时间为整秒。
- R/W为寄存器自身属性。P0B-02保留原始字并用有符号16位解释，倍率未明确时显示原码，不能虚构百分比；P0B-12不能擅自替代。
- 统一Units计算，不使用界面舍入值驱动运动；保存cm/s不依赖频繁EEPROM写入。机械校准只改控制台L，不写驱动器齿轮。
- 加载顺序为模型默认、可选启动文件、页面保存配置、保存连接目标；无效文件明确报错。真实模式启动无连接动作；显式模拟模式保持模拟生命周期。
- 原始手动RTU严格校验从站、功能、长度和CRC，不隐式重试写入；写ACK与实际读回区分。接管取消旧任务，不自动插入停止；报警、限位、反馈失鲜和普通锁定不拦截新手动写，失败不永久锁定或自动重试。用户主动停止仍取消旧排队意图；新请求仍核对连接身份。写后参考失效，基础JOG恢复不要求回零。
- 顶部状态与停止入口固定可见，动态按钮不推动布局；日志清空、暂停、分页与20,000条历史限制不能阻塞点动心跳。调试台显示伸出高度，不显示对地总高。

## 验证与残余风险

使用永久自动化测试验证协议、模拟运动/取消、并发停止、限位与报警、配置重载、读写缓存、监视周期、HTTP/SSE和页面文案。实际执行结果、测试数量和未执行项目统一记录于 [验证状态](validation.md)，不在本工作项复制易失效的测试结果。测试不得连接或控制真实设备。

现场已观察到强制DI会屏蔽物理限位，因此真实PP/HOME旧路径关闭。厂家使能完成位、通信超时自动停机、两套驱动器软限位的覆盖范围、HOME自动流程重复验证、0x4604厂家完整范围和掉电保持尚未明确，不能通过模拟或正确ACK替代验证。

设备无电机抱闸，传动系统自锁；自锁不是动态制动。停止距离、网络延迟、惯性、方向与限位可靠性依赖实际机械和固件。两点校准确定平均L/N，不独立证明名义导程、电子齿轮回退规则或全程线性。正常停止不等静止的选择已按用户要求落实，文档与界面必须保留命令确认和实际运动的区别。

## HOME失能收尾与通信停止边界

HOME静止收尾采用逐条给定读回、DI3低/高电平等待及可配置的最短保持。home_enable_hold_s默认4秒、home_disable_hold_s默认0.2秒，可在页面调试参数保存并在重启后保持。这是用户允许的实验方案，不是厂家时限或实际失能判据；完整顺序、超时和取消处理见[指令流](control-flow.md)。

通信失败按整体停止恢复处理，不以退出强制DI代替实际停机。完全断链时上位机不能保证停止命令送达；实际功率级状态及恢复效果仍须实机核验。

## 回零失败601的人工恢复

Er.601（包括现场0xE601）出现后，自动停止只确认静止，保留驱动报警并结束停止待确认，不执行会清警的HOME强制DI收尾。点击“人工故障复位”才执行完整失能收尾：若P0B-34已清零则不写P0D-01；仍为601才单次发送P0D-01=1并确认清零，再检查控制条件。通过后可由用户重新点击HOME，不自动运动、不恢复位置参考、不解除软件急停。正常成功HOME仍自动收尾，详见[恢复流程](control-flow.md#回零失败601的人工恢复)。

## 回零参数界面验收

范围：独立工具开放搜索速度、爬行速度、回零加减速度；保存重载、空值继承现场值、启动前限速校验、每项写后读回失败不得启动。非目标：自动试动、修改电子齿轮、自动调整速度或加速度。风险：实际HOME停止能力尚未验证，更高参数组合需现场验证。以模拟指令顺序、读回失败、配置重载和界面测试验收，控制流程文档同步维护。

## 操作者决策与全局停止验收

目标：移除以报警码和未知语义为依据的使能、失能、运动与人工复位门禁，保留事实显示与手册建议；顶部停止/急停明确发送256/512，不被JOG分支替代。非目标：自动复位、实机试动、解除物理限位或通信保护。验收：已知/未知报警下命令可发、限位仍约束方向、复位单次发送并核对结果、全局停止撤销旧保活且确认实际静止，通信错误不误报成功。风险：实际HOME总线停机问题尚未解决；此次不对驱动器自身保护完整性作保证。
