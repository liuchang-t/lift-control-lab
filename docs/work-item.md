# 工作项 LIFT-LAB-001：独立升降控制调试工具

## 范围与目标

本工作项维护独立工具的需求、验收标准及长期约束。工作目录为`/home/liuchang/project/lift-control-lab`；原平台`/home/liuchang/projects/patrol-platform`不在修改范围。

目标是提供可观察、可重复测试的升降控制工具，支持JOG、模式17HOME、手动RTU、报警解释、寄存器监视和参数持久化。PP定位在真实及模拟模式开放，PP定位、速度与加减速设置、正常停止及软件急停已有现场验证，有效限位下PP拒动已作为现场特性记录，内部原因未确定。

非目标包括：修改原平台、自动连接实机、自动试动、自动复位报警、自动修改电子齿轮或驱动器软限位、驱动器初始化。提交、推送、服务部署和设备操作分别依据明确授权执行。

## 验收标准

1. JOG启动前读取P0D-11，非1时才写使能，随后发方向命令；读取或写入失败不得继续旧启动。普通连续JOG不进入HOME清理。
2. 松手、失焦、页面隐藏及保活超时结束本次点动；迟到的旧停止不打断新任务，心跳只延续有效任务。
3. 物理上限禁止继续上升，下限禁止继续下降，双限位或未知映射阻止普通点动。两侧正常时，950/952不阻止双向JOG或要求重新检查。
4. 无运动只生成诊断；950组合提示具有现场依据，报警名称不确定实际限位方向，950/952均不单独阻断命令发送。驱动器原码和实际读回保留。
5. 故障复位和P03-07按钮在有效连接下可独立发送，不受报警、反馈失鲜、手动接管或旧停止流程阻塞。每次只发目标写指令，再读取对应结果；写ACK与报警清除、实际使能状态分开。
6. P03-07与故障复位按钮取消旧自动意图，但不附加设备停止命令；P0D-17/18按钮取消旧收尾，独立停止并确认静止后执行原有读写序列，不依赖旧完整收尾成功；软件急停锁存不被复位清除，活动任务不自动恢复。复位旁显示“复位前先失能”。
7. PP与HOME均使用参数准备、逐条读回、使能、最后启动顺序；HOME不要求950/952。完成参考依赖本次反馈，非固定等待或历史完成位。
8. PP与HOME通过release_bus_enable共用收尾，按控制流程实现507→511切换、DI3条件等待和配置保持。507保持期间检测到运动则中止当前收尾；511读回后反馈未稳定时先退出强制DI，再保留该阶段等待静止，不重复507。正常未稳定保留检查状态与可信参考，通信及读回异常进入停止待确认和运动状态未知处理。601保留至人工处理，故障复位不调用完整收尾。
9. PP在真实及模拟模式开放；可信参考下可从范围外返回合法目标，支持软件范围内完整行程。max_move_pulse仅保留后端兼容并在页面调试JSON中隐藏；收拢/展开使用保存的PP速度。PP控制区独立保存cm/s²加速度、减速度和急停减速度，留空沿用驱动值，下次定位准备时写入读回；保存不撤销既有回零参考。完成容差pp_tolerance_cm默认0.05cm并持久化，未启动且已在容差并确认静止时返回already_at_target。任务取消不报告实际静止，停止确认与收尾完成分开；正常减速未结束不按通信错误处理，不清除既有可信参考，前台通过stop_notice显示后台等待进展；complete仅表示到位且收尾完成，601保留时明确未执行失能收尾。
10. PP准备核对本次参考与运行参数；bus_enable_owned或P03-07实际读回1时先共用收尾，601保留仍允许人工介入。PP轮转变化比较及12秒监视仅覆盖本模式、目标及运行参数，无关HOME或JOG参数的变化或旧龄不导致误停。人工P03-07、D01和P0D-17/18接管撤销旧总线任务所有权，不自动恢复旧收尾。只读观测不干预外部主站运动。停止及连接切换取消旧排队事务，不能把旧请求发送到新目标。
11. 寄存器主值来自实际03读回，R/W为硬件属性，地址排序。按需项无固定过期周期，低频周期与失鲜阈值匹配，显式刷新返回实际成功和失败结果。
12. 高度与速度共用单位模块，机械校准只修改控制台L。配置原子保存并按明确优先级加载，损坏文件报错。

## 验证方式与状态

自动化验证覆盖协议、模拟运动、取消/停止并发、回零后连续点动、故障复位、读写缓存、配置加载、HTTP/SSE及前端交互。测试仅使用模拟器、协议替身和本机假服务，不连接真实设备。最近执行结果集中记录于[验证状态](validation.md)。

实测依据集中记录于[驱动器实测行为](drive-behavior.md)。P03-07读回0而实际仍使能、强制DI屏蔽物理输入、601清除条件、HOME停止异常均须保留适用条件；不将寄存器读回或模拟结果等同于实际功率级状态。

已记录的现场恢复策略包括：上限有效时只能先JOG下降脱离，再使用PP或HOME；错向950/952在实际限位保持有效时人工D01尝试纠正；601已自动终止并自行失能时，可按已观察样本先独立17/18使能清警，再失能；HOME下限附近重启后P10-03回到3，应检查 / 恢复后重新手动回零。以上不自动复位、自动启动或新增报警门禁，条件与来源见实测文档。

主要待验证事项为实际使能完成反馈、完全断链停机、HOME异常停止及下限附近掉电重启、PP有效限位拒动原因、软限位覆盖、机械停止距离及换算全程线性。未确认行为不构成新增权限或验收流程。
