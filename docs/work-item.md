# 工作项 LIFT-LAB-001：独立升降控制分析与调试工具

目标：保存原平台升降功能/缺陷证据，在独立本地仓库提供冻结基线和候选控制实现，验证软件指令、流程和异常处理。原仓库 `/home/liuchang/projects/patrol-platform` 不修改、提交或推送；本仓库位于 `/home/liuchang/project/lift-control-lab`。

用户已明确授权的当前范围：模式17一键回原点；全收默认回零参考上方1cm并直接显示该高度、可配置；PP/PV独立速度上下限、cm/s设置与重启恢复；统一换算；完整报警解释及处置建议；人工故障复位；上位机限位保护；驱动器软限位不明确行为标为待实机验证。当前操作台范围还包括固定状态栏、紧凑单页布局、手动RTU输入、相关寄存器监视、操作条件及恢复步骤提示、解释性悬停提示；移除用户页面中的集中平台对照和模拟故障注入。还包括无需重启的显式模拟/实机连接和断开、当前与待连接配置分离，以及单位换算依据说明；运行参数按风险分类分频监测、读取策略可见、时间整秒显示、P05-02/电子齿轮与机械导程配置核验。用户已明确授权多Agent协作。

非目标：修改原平台，驱动器自动初始化/清多圈/自学习，由正常流程自动修改P0C-13或未明确的驱动器软限位，自动恢复运动，云台/视频/机器狗业务，发布或部署生产服务。

## 验收标准

- 原源码冻结证据及校验信息保持不变。
- HOME需人工启动，验证本次完成和静止才信任参考；取消、超时、丢包与重连不能建立虚假参考。
- 普通PP/PV需可信参考；全收默认1cm，全升按配置，PP越界目标拒绝，PV保护依据明确停止模型。
- PP/PV速度独立、原子保存、设备及模拟/实机隔离；重启恢复设置不恢复使能、运动或可信度。
- 单位换算统一，内部精度与显示精度分离，异常数值和溢出拒绝。
- 手册59项故障/警告有解释、来源、建议和独立平台策略；未知码保守处理。
- 人工复位确认停止与当前报警、发送一次并读回，不自动重启；物理限位有效、未知或禁止复位情况不发通用复位写入。
- 正常控制对P0C-13与两套软限位只读；手动总线允许用户明确编辑的原始写入，不自动生成参数内容或重试；界面可明确选择自动CRC，写后参考失效；参数差异不自动覆盖安全配置。
- 测试覆盖故障注入、协议、HTTP/SSE、配置恢复、速度和HOME、报警/复位、原基线对照；界面检查与实机验证边界明确。

- 顶部状态与停止入口在操作面板滚动时仍可见；不因寄存器/日志增长撑开页面。
- 当前未满足条件、拒绝原因与恢复步骤可见；回零成功后低于软件工作下限时明确提示先全收，不能误导为可直接点动。
- 手动写优先接管并取消自动任务，不要求预先进入维护模式；RTU与普通控制共用执行/传输边界，明确展示允许范围和限制；无隐式重试写入，不将写回显标作实际读回值。
- 自动CRC默认开启，输入不含CRC，显示最终帧；关闭后输入完整帧；长度校验拒绝重复CRC，不静默修改指令数据。
- 寄存器监视包含地址、用途、宽度、值、来源和新鲜度；缓存与实际读回区分，刷新不抢占运动保护通信。
- 集中平台和故障注入只保留开发测试接口，不作为现场操作面板功能。

- 选择或保存连接目标不自动连接；real需明确确认；连接成功不恢复运动许可或可信参考。
- 切换/断开仅对本后端活动任务执行停止确认；纯监视不发停止，停止失败保留旧连接保护任务；断开后的状态、参数和寄存器查看不得隐式重连。
- 单位说明区分指令单位、rpm与编码器单位，注明N/L来自原项目且需实机核验；P05-02=0不能当作电子齿轮已验证。

- 动态监测区分单位/参考、运动配置、普通诊断参数及工具已确认的自写；外部变化不得被静默吸收为合法基线。本后端活动任务才可触发参数保护停止；空闲关键参数变化仅撤销本工具许可/参考并提示。
- 私有客户端共享操作，不设独占、获取/释放、续期或租约超时停机；旧lease接口兼容无操作。只读观测不干预别的客户端或外部主机/485运动，不因“未请求运动”自动停止或自动失效参考。检查 / 恢复是运行条件核验，不是权限授予。
- 快速状态采集与参数扫描分层，避免每个状态周期全量读参挤占停止通信；显示扫描时间、新鲜度和未监视范围。
- 时间在用户界面按整秒表达，不降低后台时间比较精度。
- P05-02=0时展示电子齿轮候选推导及未证实边界，P05-02宽度歧义保留原始字；每电机转机械距离可配置但不能自动当作实测事实；校准仅修改上位机L，按旧L×实测/指令位移修正，不要求修改驱动器齿轮，保留cm/s用户设置。

## 风险与验证方式

设备无电机抱闸，传动系统自锁。自锁不是动态制动；强制DI与物理限位、HOME参考重复性、网络中断、停止距离、实际导程/方向和两套软限位仍需现场验证。模拟器是寄存器级软件模型，不是驱动固件或机械模型认证。

先离线测试与浏览器交互，再由现场按明确条件执行低速小位移验证。本轮不会连接真实驱动器。最终运行命令、结果与未验证事项维护在 `validation.md`；工作项不替代原始过程日志。
